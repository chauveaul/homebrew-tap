# chauveaul/homebrew-tap

Homebrew formulas for [vibe-rpc](https://github.com/chauveaul/vibe-rpc), Discord Rich Presence and coding analytics for Antigravity and Claude Code.

```sh
brew install chauveaul/tap/vibe-rpc
vibe-rpc setup
```

Update with `brew upgrade vibe-rpc`.

Formulas in `Formula/` are generated and pushed automatically by the vibe-rpc release workflow. Don't edit them by hand.
